# KeTAS 项目面试问答速查

> 用途：面试前快速梳理项目实现。回答时先说结论，再补公式、参数和局限。本文以当前代码为准，而不是以旧文档或文件名为准。

## 一分钟项目介绍

### Q1：请用一分钟介绍这个项目。

这是一个面向瘢痕皮肤图像的可解释纹理分析系统 KeTAS。它首先用三分类 U-Net 把图像分成正常皮肤、瘢痕周边受影响区域和瘢痕主体；随后只在目标区域内用 Gabor 滤波、二值化和 Canny 提取皮纹；再用 Scharr 梯度和结构张量估计无向纹理轴。系统在局部圆形邻域中计算纹理密度和方向一致性，并按默认 0.7 和 0.3 加权得到 Severity Map。Severity 又被离散成 Presence Level，并通过分位数、连通域和形态学处理定位最严重区域。最后输出 Severity Map Overlay、Presence Map Overlay，以及区域或局部 Direction Map。工程上提供 Streamlit Demo、参数持久化、批处理和过程流程图。

### Q2：这个项目解决的核心问题是什么？

它不是单纯判断“有没有瘢痕”，而是回答三个更细的问题：

1. 瘢痕及其周边的有效分析范围在哪里；
2. 局部皮纹有多密、方向有多一致，因此相对严重度如何分布；
3. 高严重度连通区域在哪里，其主要纹理轴朝什么方向。

### Q3：为什么使用“深度学习分割 + 传统视觉”，而不是完全端到端？

U-Net擅长解决边界和语义区域定位；Gabor、结构张量和圆统计则能提供可解释的纹理密度、方向和一致性。对于样本量有限的科研项目，这种混合方案比直接训练一个端到端严重度网络更容易解释和调试，也不需要额外的像素级严重度标注。代价是后半部分包含人工参数，需要进一步验证其临床泛化能力。

## 整体流程

### Q4：完整处理流程是什么？

```text
输入图像
  -> 三分类 U-Net 分割
  -> 目标区域形态学修正
  -> Gabor 纹理增强
  -> 自适应阈值 + Canny + 膨胀得到 Texture Lines
  -> Scharr + 结构张量得到纹理轴
  -> 局部密度 + 局部方向一致性得到 Severity Map
  -> threshold/quantile 分级得到 Presence Level
  -> 候选框搜索 + 高分连通域得到 Presence Map Overlay
  -> 区域/局部双角均值得到 Direction Map
```

### Q5：最终结果和中间结果怎么区分？

当前 Process Overview 的 RESULTS 区域展示：

- Severity Map Overlay：连续严重度叠加在原图上；
- Presence Map Overlay：提取出的高严重度连通区域叠加在原图上；
- Direction Map：优先展示 Local Direction Map；若关闭 Local，则展示 Regional Mean Direction Map。

Texture Lines、Texture Line Overlay、Pixel-Level Texture-Axis Map、Presence Level 等属于中间可解释结果。

## U-Net 分割模型

### Q6：模型到底是 U-Net 还是 TransUNet？

当前代码实际实例化的是标准卷积 U-Net，没有 Transformer 模块。权重文件名中的 `best_trans_unet_model_...pth` 里的 `trans` 表示训练时启用了 transformation/data augmentation，即数据增强，不代表 Transformer。因此面试时不能把它说成 TransUNet。

### Q7：U-Net 的结构参数是什么？

编码器通道为 `64 -> 128 -> 256 -> 512 -> 1024`，共四次 2×2 最大池化。每层使用两次 `3×3 Conv + BatchNorm + ReLU`。解码器用四次 `2×2` 转置卷积上采样，并与编码器对应层做 skip connection。最后用 `1×1 Conv` 输出 3 个类别。当前模型参数总数为 **31,043,651**。

### Q8：为什么选择 U-Net？

U-Net适合像素级分割，skip connection 能把浅层边缘细节传给解码器，对边界不规则且数据量有限的医学图像比较合适。项目后续计算依赖准确的空间掩膜，因此分割模型比单纯分类模型更合适。

### Q9：三个类别分别是什么？

- `0`：正常皮肤/背景；
- `1`：KELOID_BOUNDARY 所定义的受影响区域，在主体被覆盖为类别 2 后，可理解为瘢痕周边或 intertidal zone；
- `2`：KELOID_BODY，瘢痕主体。

生成标注时先把 KELOID_BOUNDARY 多边形写成 1，再把 KELOID_BODY 写成 2，因此主体区域会覆盖原来的类别 1。

### Q10：输入输出尺寸是什么？

推理前把 RGB 图像缩放到 `256×256`，模型输出形状为 `3×256×256` 的 logits，通过 `argmax` 得到类别图，再用最近邻插值恢复到原始尺寸。最近邻插值可以避免类别编号被线性插值成无意义的小数。

### Q11：训练参数是什么？

- 数据划分：训练集 80%，验证集 20%，`random_state=42`；
- batch size：8；
- 损失函数：多分类交叉熵 `CrossEntropyLoss`；
- 优化器：Adam；
- 学习率：0.001；
- 最大 epoch：100；
- early stopping patience：20；
- 保存标准：验证损失最低；
- PyTorch 和 NumPy 随机种子：42。

### Q12：数据增强怎么做？

启用 `-Trans 1` 后，训练集扩成三倍：原图、颜色抖动版本 1、颜色抖动版本 2。增强主要改变 brightness、contrast、saturation 和 hue。验证集不增强。这里的 `Trans` 是 transformation，不是 Transformer。

### Q13：目前模型评估有什么不足？

训练主要以验证集交叉熵选择模型，现有代码没有形成完善的 Dice、IoU、每类召回率、独立测试集和跨设备外部验证报告。面试时应把它作为下一步工作，而不要声称模型已经完成临床有效性验证。

## 有效分析区域

### Q14：为什么分割后还要做形态学处理？

原始分割边界可能有小孔洞、断裂或边缘抖动。纹理统计又对分析区域边界敏感，因此对类别 1 掩膜依次做闭运算、动态膨胀、动态腐蚀，并只保留最大 8 连通域，得到更稳定的 Effective Intertidal Zone。

### Q15：形态学参数是多少？

- 闭运算：`5×5` 椭圆核；
- 膨胀距离：`image_height // 30`，核尺寸为 `2d+1`；
- 腐蚀距离：`max(1, image_height // 80)`，核尺寸为 `2d+1`；
- 连通性：8 邻域，只保留最大连通域。

### Q16：为什么先膨胀再腐蚀？

膨胀用于覆盖瘢痕边界附近可能遗漏的纹理，随后腐蚀减少过度扩张并让最终区域更稳定。这并非严格的标准闭运算，因为膨胀和腐蚀尺度不同，而是针对分析区域设计的经验性空间修正。

## Gabor 与纹理线提取

### Q17：Gabor 使用几个方向、几个波长、几个核？

以当前代码为准：

- 方向：`0°、45°、90°、135°`，共 4 个；
- 波长：`10、15`，共 2 个；
- 总核数：`4 × 2 = 8`。

代码中的 `np.arange(10, 20, 5)` 只会产生 10 和 15，不包含 20。旁边“3个波长”的旧注释是错误的，不能按注释回答。

### Q18：Gabor 核的其他参数是什么？

- kernel size：`9×9`；
- sigma：3.0；
- gamma：0.5；
- psi：0；
- 4 个方向；
- 2 个波长。

各个滤波响应被转换为灰度后累加，再归一化到 0～255。

### Q19：为什么用 Gabor？

Gabor 同时具有空间局部性和方向选择性，适合增强具有特定方向和尺度的条纹结构。多方向、多波长组合能减少只用单个核造成的方向偏置。

### Q20：Gabor 后怎样得到二值纹理线？

先对归一化响应使用 OpenCV 高斯自适应阈值：邻域 `11×11`，常数 `C=2`；然后使用 Canny，低高阈值分别为 50 和 150；最后用 `3×3` 核膨胀一次增强线条，并用修正后的区域掩膜裁剪，得到原尺寸 0/255 单通道 Texture Lines。

### Q21：项目用到了 Canny 吗？

用到了。Canny 位于 Gabor 响应二值化之后，用于把响应区域转成边缘纹理线，阈值为 50 和 150。

### Q22：为什么 Gabor 后还要自适应阈值？

Gabor 输出是连续强度响应，不是明确的纹理线。自适应阈值根据局部亮度决定前景，比全局固定阈值更能适应皮肤图像光照不均。随后 Canny 从这些响应区域中提取更细的边缘结构。

### Q23：Texture Line Overlay 是怎么画的？

把 Texture Lines 中大于 0 的白色纹理像素当作掩膜，将其变成红色并以 30% 透明度叠加到原图；黑色像素完全透明，非纹理区域逐像素保持原图不变。因此它不是把整张黑底纹理图与原图做全局加权。

### Q24：纹理提取方法有什么局限？

Gabor 参数、阈值和 Canny 参数是经验设定；不同拍摄距离、清晰度、肤色和光照可能改变响应。当前还是把不同 Gabor 响应直接累加，可能出现响应抵消或尺度偏置。更严格的方案可以比较响应绝对值/能量、进行多尺度标定，并用人工纹理标注验证召回率。

## 纹理方向与方向一致性

### Q25：纹理方向怎么计算？

在纹理图上用 Scharr 计算横纵梯度 `dx, dy`，构造结构张量：

$$
J=\begin{bmatrix}dx^2 & dx\,dy\\dx\,dy & dy^2\end{bmatrix}
$$

三个张量分量经过高斯平滑后逐像素特征分解。取最大特征值对应向量，再加 90°，把梯度法向转换为纹理切向轴。

### Q26：结构张量平滑参数如何确定？

$$
\sigma=\max\left(3,\left\lfloor\frac{\min(H,W)}{100}\right\rfloor\right)
$$

核尺寸为 `6σ+1`。同时只计算能量大于有效区域最大能量 `1e-6` 倍的位置，低能量位置记为 NaN。

### Q27：为什么方向是 0～180°，不是 0～360°？

纹理是一条轴而不是带天然箭头的向量。0° 和 180° 表示同一条纹理轴，所以其周期是 180°。这类数据称为 axial data，不能直接用普通角度平均。

### Q28：局部方向一致性公式是什么？

先把每个纹理轴角度翻倍，再计算平均单位向量长度：

$$
C=\sqrt{\left(\frac{1}{N}\sum_i\cos 2\theta_i\right)^2+
\left(\frac{1}{N}\sum_i\sin 2\theta_i\right)^2}
$$

`C` 范围为 0～1。方向越集中，向量越不互相抵消，C 越接近 1；方向越分散，C 越接近 0。

### Q29：计算一致性前会先得到整体平均方向吗？

Severity Map 中的一致性不需要先显式求平均方向。代码直接计算局部 `mean(cos 2θ)` 和 `mean(sin 2θ)`，再取向量长度。它隐含包含了圆形均值信息，但一致性只使用长度，不使用均值角度本身。

### Q30：为什么一致性不受平均方向影响？

如果所有角度整体旋转同一个角度，双角向量也只会整体旋转，平均向量的方向会变，但长度不变。因此一组都集中在 45°和一组都集中在 90°可以得到相同的一致性；一致性衡量的是“集中程度”，不是“朝哪个方向”。

### Q31：45°附近有同样的摆动和 90°附近有同样的摆动，一致性一样吗？

理论上相同。只要两组角度的离散程度相同，仅平均方向不同，C 就相同。若一组跨越 0°/180°边界，双角法也能正确处理，不会把 179°和 1°误认为差 178°。

### Q32：平均纹理轴怎么计算？

区域方向使用双角圆均值：

$$
\bar\theta=\frac{1}{2}\operatorname{atan2}
\left(\frac{1}{N}\sum_i\sin2\theta_i,
\frac{1}{N}\sum_i\cos2\theta_i\right)\pmod{\pi}
$$

它得到的是无向轴，范围为 0～180°。

## Severity Map

### Q33：局部纹理密度怎么算？

在半径为 r 的圆形邻域内：

$$
D(p)=\frac{\text{纹理前景像素数}}{\text{有效区域像素数}}
$$

分母只计算目标掩膜内的有效像素，因此靠近掩膜边界时不会被区域外背景简单稀释。

### Q34：Severity Score 公式是什么？

$$
S(p)=w_dD(p)+w_cC(p)
$$

默认 `w_d=0.70`、`w_c=0.30`。代码会先将两个权重除以权重和，因此用户即使输入的和不等于 1，也会自动归一化。

### Q35：为什么密度权重大于一致性？

当前设计把纹理密集程度视为主要信号，把方向一致性作为组织性修正，因此默认 0.7/0.3。这是可解释的经验权重，不是通过监督学习拟合得到的最优权重。严谨回答应说明后续需要通过标注严重度、消融实验和外部验证确定权重。

### Q36：Severity Map 是绝对严重度吗？

不是。加权分数在每张图的有效掩膜内做 min-max 归一化：

$$
S_{norm}=\frac{S-S_{min}}{S_{max}-S_{min}}
$$

所以它主要表达单张图内部的相对严重度分布，不能直接把两张图的 0.8 当作完全相同的临床严重程度。这是面试中必须主动说明的限制。

### Q37：Heatmap Radius 是什么？

它是计算局部密度和一致性的圆形邻域半径。半径大，结果更平滑、对局部噪声不敏感；半径小，空间分辨率高但波动更大。

### Q38：动态半径怎么计算？

以图像短边 920 像素对应半径 80 为参考：

$$
r=\operatorname{clip}\left(\operatorname{round}\left(80\frac{\min(H,W)}{920}\right),12,96\right)
$$

Demo 也允许固定半径，保存的固定默认值为 40。

## Presence Level 与高严重度连通区域

### Q39：Presence Level 和 Severity Map 有什么区别？

Severity Map 是 0～1 的连续相对分数；Presence Level 是把连续分数按阈值离散成若干等级，用蓝到红的颜色显示。离散结果更容易展示区域等级，但会损失连续信息。

### Q40：Presence 的 threshold 和 quantile 有什么区别？

- threshold：直接在 0～1 的归一化分数上用固定阈值分级；
- quantile：根据当前图像有效区域内的分数分布，用百分位数换算实际阈值。

默认是 2 级、quantile 模式、切分点 80%，即大约最高 20% 为高等级。由于分数可能并列，实际像素比例不一定严格等于 20%。

### Q41：Worst Area Severity Percentile (q) 属于 threshold 还是 quantile？

它始终是 quantile，与 Presence Split Mode 的选择相互独立。默认 q=80，先计算有效区域分数的第 80 百分位阈值，再保留大于等于阈值的像素。它不是“保留 80%”，而是大约保留最高 20%。

### Q42：高严重度区域怎样做连通处理？

1. 在候选框内寻找有效掩膜中的最高分点作为种子；
2. 对全局 `score >= q分位阈值` 且位于有效掩膜内的像素做二值化；
3. 使用 8 邻域连通组件；
4. 只保留包含种子的连通域；
5. 使用 `7×7` 椭圆核做闭运算；
6. 提取外轮廓并填充轮廓内部；
7. 最后再次与有效掩膜相交。

因此最终区域是闭合且填充的，不只是边缘框。

### Q43：Presence Map Overlay 是什么？

它不是简单的 Presence Level 彩色叠加，而是把通过候选框、分位阈值、种子连通域、闭运算和轮廓填充得到的高严重度区域叠加在原图上。多个区域按严重顺序从红色逐渐过渡到黄色。

## Worst Area 搜索

### Q44：Worst Area 的候选框怎么选？

对每个可能的方框中心，用卷积快速计算框内分数总和和有效掩膜像素数。目标函数是：

$$
Objective=\frac{\sum_{p\in box\cap mask}S(p)}{|box\cap mask|}
$$

即只统计掩膜内像素的平均严重度。框中心必须在有效掩膜内，并满足最小掩膜覆盖率；多个框之间不能重叠，也不能覆盖已经选出的连通区域。

### Q45：Worst Area 默认参数是什么？

- Box Size Mode：Fixed；
- Box Size：80 像素；
- Number of Boxes：2；
- Minimum Mask Coverage：0.30；
- Worst Area Severity Percentile：80。

如果没有候选框满足最低覆盖率，当前代码会退回到中心有效但不满足覆盖率的候选集合。这保证算法尽量给出结果，但也是一个需要在严格实验中记录的工程性 fallback。

### Q46：为什么先找框，再找连通域？

框提供稳定的空间种子和多区域排序，避免全图中大量零散高分像素都被当作独立结果；连通域再把矩形定位转成符合真实形状的区域。框是搜索工具，不是最终 Presence Map Overlay 的形状。

## Direction Map 与箭头

### Q47：箭头起点怎么选？

先取有效分析区域外边界向内 10 像素形成的带状区域，与当前高严重度连通域求交；在交集内选择 Severity 最高的点作为箭头起点。如果交集为空，才回退到整个连通域内的高分点。这样使箭头更接近瘢痕外侧，用于表达向外的可视化方向。

### Q48：Regional Mean Direction Map 和 Local Direction Map 有什么区别？

- Regional：对整个 Worst Area 内的所有有效纹理轴做双角平均；
- Local：以同一个箭头起点为中心，在可调 `Local Direction Radius` 圆形邻域内做双角平均，默认半径 40。

Regional 更稳定、代表整体；Local 更强调箭头起点附近的局部纹理。

### Q49：无向纹理轴怎么变成有向箭头？

双角均值得到的是 `θ` 与 `θ+180°` 等价的轴。代码以类别 2 瘢痕主体包围盒中心作为 anchor，比较两个候选方向与“anchor 指向箭头起点”的向外向量，选择点积非负的方向。如果类别 2 不存在，则回退到类别 1 中心。

### Q50：箭头能否证明瘢痕真实生长方向？

不能直接这样声称。模型计算的是图像中的纹理轴，箭头正负方向是通过“朝外”规则人为消歧的可视化约定。它可以作为可能的发展方向提示，但若要解释成生物学或时间上的生长方向，需要纵向随访数据验证。

### Q51：箭头长度和粗细怎么定？

箭头长度为图像短边的 14%，因此不同尺寸图像中保持相对一致。粗细同时考虑区域平均密度和方向一致性：

$$
d_n=clip(D/0.30,0,1),\quad c_n=clip(C,0,1)
$$

$$
t=\sqrt{d_nc_n}
$$

$$
width=\max\left(2,\min(H,W)\times0.10(t-0.5)\right)
$$

外层先按该公式计算并设置 2 像素下限，实际绘制函数又把轴宽限制为至少 4 像素，因此最终可见轴宽下限是 4 像素。箭头用闭合多边形轮廓绘制，是空心箭头。密度越高且方向越一致，通常越粗；低分区域会因为最小宽度限制而出现差异压缩。

### Q52：为什么粗细用密度和一致性的几何平均？

几何平均要求两个因素都不能太低：如果纹理很密但方向很乱，或方向很一致但纹理极少，箭头都不应过粗。它比算术平均更能抑制单一指标过高造成的夸大。

## Demo 与工程实现

### Q53：Demo 为什么分“完整运行”和“只重算指标”？

完整运行包括 U-Net、纹理提取和方向估计，耗时较大；调整 Severity 权重、半径、Presence 阈值或 Worst Area 参数时，不需要重新做前面的分割和纹理提取，只重算指标和区域即可，提高交互效率。

### Q54：设置如何持久化？

Display Settings 保存到项目根目录的 `web_demo_display_settings.json`。保存采用临时文件后替换的方式，降低写到一半损坏配置的风险。该文件被 `.gitignore` 忽略，因此每台电脑保留自己的显示偏好，不污染 Git 历史。

### Q55：如何处理 Streamlit 页面切换造成的参数丢失？

Streamlit 会清理没有在当前页面渲染的 widget key。项目额外维护参数缓存，在 Analysis、Process Overview 和 Display Settings 之间切换时恢复参数；缺失 key 会从缓存或默认参数补齐。

### Q56：如何支持 Windows 中文路径？

主要图像读取使用 `np.fromfile + cv2.imdecode`，写入使用 `cv2.imencode + ndarray.tofile`，绕开部分 OpenCV 版本对 Windows 非 ASCII 路径支持不稳定的问题。路径通过 `pathlib.Path` 基于项目根目录构造，不依赖固定盘符。

### Q57：为什么另一台电脑可能缺少 Texture Lines？

`runtime/texture` 属于运行时中间产物，不随 Git 仓库分发。若只复制了部分历史输出而没有运行完整流程，`only_texture_line_*.png` 可能不存在。当前 Demo 会把它显示为缺失结果而不是崩溃；要生成该图仍需在目标电脑上执行一次完整分析。

### Q58：Process Overview 是怎么实现的？

Python/OpenCV 把各阶段缩略图、节点、箭头和 RESULTS 区域合成为一张 `1920×940` 流程图，再由 Streamlit 自适应宽度显示。这样在常见 16 英寸屏幕上能看到全貌。纳入哪些图片由持久化 Display Settings 控制。

### Q59：项目如何保证结果可复现？

训练设置了随机种子 42；每次 Web 分析会在输出目录保存 `run_params.json`，记录模型路径、权重、半径、Presence 配置、Worst Area 百分位和实际使用阈值。代码用 Git 分支管理版本。但 GPU 算子仍可能存在非完全确定性，拍摄条件也需要额外标准化。

## 老师可能追问的批判性问题

### Q60：这个项目最重要的三个局限是什么？

第一，Severity 是单图内 min-max 相对分数，不是跨患者可直接比较的绝对临床量表。第二，Gabor、Canny、权重和分位数包含经验参数，尚需系统消融和外部数据验证。第三，箭头表示纹理轴经过“向外”规则消歧，不等于从时间序列学习出的真实生长方向。

### Q61：如果重新做一次，你最先改进什么？

1. 建立独立测试集和跨设备外部验证，报告每类 Dice/IoU、边界误差和置信区间；
2. 标注专家严重度或纵向变化，用数据学习 Severity 融合权重并验证方向解释；
3. 对 Gabor 方向、波长、半径、Canny 和分位数做消融与敏感性分析；
4. 做颜色校正、尺度标定和拍摄协议标准化，使跨图比较更可靠。

### Q62：为什么不直接用模型预测 Severity Map？

目前没有足够的像素级严重度真值。直接训练会把主观标签和小样本偏差一起学进去。现方案用可解释特征构建初版评分，适合研究探索。获得可靠专家标注后，可以训练回归或排序模型，并把当前密度、一致性作为可解释辅助特征。

### Q63：怎样证明方向一致性设计合理？

理论上，双角法正确处理 180°周期的轴向数据，并具有整体旋转不变性。实验上应构造已知方向和噪声水平的合成纹理，验证 C 随角度离散程度单调下降；再用人工方向标注比较误差，并对窗口半径做敏感性分析。

### Q64：怎样证明 0.7/0.3 和 q=80 合理？

当前只能说它们是可调的经验默认值，不能声称统计最优。合理验证方式是网格搜索或贝叶斯优化，并在独立验证集上比较与专家评分、复发风险或纵向扩展的相关性；同时报告不同参数下结果的稳定性。

### Q65：项目中最容易说错的事实有哪些？

- 模型是普通 U-Net，不是 Transformer U-Net；
- `trans` 文件名表示数据增强；
- Gabor 实际是 4 个方向、2 个波长、8 个核；
- Canny 确实被使用，阈值为 50/150；
- Severity 是单图相对分数，不是绝对临床严重度；
- Worst Area q=80 是第 80 百分位，约保留最高 20%；
- Worst Area q 始终用 quantile，与 Presence Split Mode 独立；
- 方向一致性不评价平均方向，只评价集中程度；
- 箭头的正方向是向外规则赋予的，不是模型预测的时间方向；
- 8 扇区分析已在当前 Demo 流程中弃用。

## 面试现场答题模板

### Q66：遇到不确定的具体参数，怎么回答比较稳妥？

可以说：“我先区分设计意图和当前实现。设计上是多方向、多尺度 Gabor；当前提交中的代码实际为 4 个方向、波长 10 和 15，共 8 个核。我会以代码为准，同时把旧注释不一致列为需要清理的技术债。”这种回答比猜一个数字更可靠。

### Q67：老师质疑人工规则太多，怎么回应？

可以回答：“这个质疑成立。当前阶段的目标是建立可解释基线，并明确每个局部评分来自密度还是方向一致性。人工规则带来可解释性，也带来泛化风险，所以我把关键参数暴露在 Demo 中并保存快照。下一步不是继续堆规则，而是用独立标注、消融实验和外部验证决定哪些规则保留，哪些改成学习型参数。”

### Q68：老师问项目创新点，怎么避免夸大？

可以回答：“创新点不在于发明了 U-Net、Gabor 或结构张量，而在于把语义分割、轴向圆统计、局部严重度、分位连通区域和方向可视化整合成一套可解释且可交互的流程。它的价值是从一张图提供区域、程度和纹理方向三个层次的信息。是否具有临床创新价值，还需要外部数据和纵向研究证明。”
