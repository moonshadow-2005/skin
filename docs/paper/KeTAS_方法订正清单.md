## 3. 建议修复：当前代码可能存在的算法问题

### 3.1 无纹理像素可能被纳入方向一致性

#### 当前问题

`compute_orientations()` 对有效掩膜内所有像素计算结构张量方向。即使某个位置没有
纹理，或者结构张量接近零，`np.linalg.eigh()` 仍会返回一个特征向量。

随后方向有效性只判断：

```python
~np.isnan(orientations) & (region_mask > 0)
```

没有要求该像素是纹理像素，也没有设置最小梯度能量或特征值阈值。

结果可能是：

- 无纹理区域获得没有物理意义的固定方向；
- 无纹理像素参与双角平均；
- 局部方向一致性被人为抬高；
- 严重度图在低纹理区域仍可能因一致性项得到较高分数。

代码位置：

- `src/local_score_heatmap.py:120-148`
- `src/local_score_heatmap.py:337-355`
- `web_demo.py:450-467`

#### 推荐修复

最低限度应将方向有效掩膜限制为纹理像素：

```python
orient_valid = (
    ~np.isnan(orientations)
    & (texture_binary > 0)
    & (region_mask > 0)
).astype(np.float32)
```

更稳健的方案是根据结构张量能量设置阈值：

```text
lambda_1 + lambda_2 > T_gradient
```

或者同时限制纹理像素、梯度幅值和结构张量相干性。

修复后需要重新检查严重度图、Worst Area 和方向图，因为该变化可能显著改变结果。

### 3.3 Gabor 核归一化存在稳定性风险

当前代码使用：

```python
kern /= 1.5 * kern.sum()
```

Gabor 核通常具有接近零的正负响应总和。使用核元素总和做除数可能导致：

- 不同波长核的放大比例差异很大；
- 核总和接近零时数值不稳定；
- 结果受 OpenCV 版本和浮点误差影响；
- 滤波器之间不具备一致的能量归一化。

代码位置：`skin.py:171-173`。

建议使用 L1 或 L2 能量归一化，例如：

```python
kern /= np.sqrt(np.sum(kern * kern)) + 1e-8
```

如果保留当前方法，需要在论文中明确该归一化公式，并报告稳定性验证。

### 3.5 高斯权重公式需要使用二维距离

论文当前写为：

```text
w(i,j) = exp(-(i-j)^2 / (2 sigma^2))
```

对于二维图像像素，`i` 和 `j` 应表示二维坐标，建议写为：

```text
w(i,j) = exp(-||x_i - x_j||_2^2 / (2 sigma^2))
```

否则 `(i-j)^2` 容易被理解为一维索引差。

此外，论文写 `sigma = 0.01 x 图像宽度`，代码实际使用：

```python
sigma = max(3, int(min(height, width) / 100))
```

即按图像短边计算，并设置最小值 3。论文也应同步修改。

- 是否按患者划分，避免同一患者图像同时进入训练集和验证集；
- 随机种子；
- 数据增强是否仅用于训练集；
- 最终训练轮数和触发早停的轮数；
- 分割指标，例如 Dice、IoU、灵敏度和特异度。

当前代码使用 `CrossEntropyLoss`、Adam、学习率 `0.001`、批大小 `8`、最多
`100` 个 epoch、早停 patience `20`。这些参数与论文基本一致，但仍需补充数据划分
与最终性能。

### 4.4 方向箭头的临床含义需要谨慎表述

结构张量和双角平均只能估计无向纹理轴：

```text
theta 与 theta + 180° 等价
```

代码通过“相对于瘢痕主体中心向外”的先验选择箭头方向。因此，箭头有向性不是由
单张纹理图像独立识别出来的，而是由纹理轴与空间先验共同决定。

论文应避免直接写成“算法从纹理中预测了唯一传播方向”，更准确的表述是：

> 算法首先估计无向纹理主轴，再结合瘢痕主体与潮间带的相对空间位置，将主轴定向为
> 指向瘢痕外侧的候选侵袭方向。

该方向预测需要通过纵向随访验证。

### 4.5 相对分数不能直接解释为绝对侵袭程度

由于当前严重度图按单幅图像 Min-Max 归一化，Presence 和 Worst Area 又主要使用
图内百分位，因此它们反映的是图像内部的相对高风险位置。

若要称为可跨患者、跨时间比较的 Ke 指数，需要进一步完成：

- 统一物理尺度；
- 统一图像采集；
- 固定特征参数；
- 使用训练集或参考人群统计量进行归一化；
- 评估重复拍摄的组内相关系数；
- 评估不同设备、光照和距离下的稳定性；
- 与临床结局或随访增长方向进行独立验证。
